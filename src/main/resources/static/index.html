URL Shortener

A minimal demo of each feature. Every action below calls the real API.

1. API key

Creating links and reading stats need the key. Under docker compose, paste the local demo key from the README. The page keeps it in memory only, though your browser may offer to save it as a password.

2. Shorten a URL

Only http/https with a host, up to 2,048 characters. The stored destination is normalized (scheme and host lowercased).

3. Click stats

Uses the default date range. Clicks are recorded in the background, so refresh after following the link.

4. Error contract

Every failure is an RFC 7807 problem response, and none echoes the submitted URL or the key. The key is checked first, so the 400 and 404 examples need it.
